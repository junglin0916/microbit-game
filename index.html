Micro:Bit setup reminder
1. Add the Bluetooth extension in MakeCode (擴展)
2. Gear icon → Project Settings → No Pairing Required
3. Flash this code to your Micro:Bit:

bluetooth.startUartService()
basic.forever(function () {
  bluetooth.uartWriteString("" + input.acceleration(Dimension.X) + "\n")
  basic.pause(50)
})
4. Click Connect Micro:Bit above and select your device
5. Tilt left/right to dodge the falling rocks!
